# Fixed working prescriptions

The advanced lift editor and workout weight panel accept whole-number set and rep targets for eligible straight-set lifts. Bounds match the existing Custom Training builder: 1–20 working sets and 1–50 reps. Leaving the displayed default unchanged keeps the original plan. Overrides are saved per programme and lift. Custom Training uses its existing per-day compound template and keeps manual progression.

An edit uses the same numbered slots in the current workout. The first prescribed slots are evaluated against the revised rep target. Their original actual load, reps, and recorded target are preserved. Recorded slots beyond the reduced count stay visible and are included in volume and History. The existing explicit extra sets are separate from prescribed slots in the core engine. An expansion revokes a previously earned result until every newly required slot is recorded. A completed fixed prescription succeeds when all required slots reach the target. A recorded miss follows the existing straight-set failure streak and decision paths. Finishing with unrecorded required slots uses the existing incomplete-workout flow.

The fixed override applies to LP/RPT straight mode and eligible standalone straight lifts in HLM and 4-Day Split. An RPT prescription has unequal targets, prescribed load drops, and a rescue plan that depends on what happened in earlier sets. HLM/Split Squat and Bench share a Heavy driver with a mandatory top set at index 2 and linked Light or Medium roles. HLM Light and Split day 4 Deadlift have an optional single whose trigger depends on the first set reaching five reps. Those prescriptions retain their existing plan. Supporting arbitrary fixed counts there needs a reviewed mapping for the top set, backoffs, and optional singles, plus a decision about which exposures drive progression. Custom RPT retains its existing plan editor. Bodybuilding is outside the override.

Existing data with no override reads the original prescriptions. The core override travels with existing backup data, while interrupted workouts follow the established local-first policy. The release still needs physical Android acceptance.
